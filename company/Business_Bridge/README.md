# Datos de trabajo de Business Bridge

Esta carpeta es el conjunto de datos canónico de trabajo para el piloto actual de Business Bridge.

## Contenido

- `data.json`: perfil canónico de la empresa y metadatos de apoyo
- `originales/`: documentos fuente originales para el piloto
- `actualizados/`: artefactos revisados o procesados

## Regla

No mantengas otra copia activa de estos mismos datos en `mvp/company/Business_Bridge/`.
El runtime lee y escribe directamente en esta carpeta raíz.
