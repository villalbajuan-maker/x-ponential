# Sprints Review

Esta carpeta contiene el documento de planificacion y seguimiento de cada sprint.

## Proposito

Cada archivo es el documento de vida del sprint: se crea al iniciar la semana con la agenda y los entregables comprometidos, se actualiza durante el sprint con el estado de cada entregable, y al arrancar el siguiente sprint se completa la seccion de Review con los resultados y aprendizajes.

## Que va aqui y que va en reuniones/

| Carpeta | Contenido |
| --- | --- |
| `sprints_review/` | Planificacion + entregables + estado + review del sprint. Es el primer documento que se abre en cada reunion de sprint. |
| `reuniones/` | Acta de la reunion: temas tratados, acuerdos, decisiones y proximas acciones que surgieron en la sesion. |

## Convencion de nombres

`sprint-N-YYYY-MM-DD-YYYY-MM-DD.md`

Ejemplo: `sprint-1-2026-07-15-2026-07-22.md`

## Recomendacion

Mantener la seccion de entregables actualizada durante el sprint para que la reunion de review sea una revision de estado, no una reconstruccion de lo que paso.
