# Pruebas de integración

Coloca aquí pruebas que toquen archivos, muestras o varias capas al mismo tiempo.

Ejemplos típicos:

- registros de extracción guardados y cargados desde disco
- regex de OCR sobre texto de muestra
- flujo de documentos que usa el sistema de archivos

Estas pruebas pueden usar las muestras de `tests/fixtures/`.
