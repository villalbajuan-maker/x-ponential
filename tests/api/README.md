# Pruebas de API

Coloca aquí pruebas de request/response para endpoints de FastAPI.

Ejemplos típicos:

- verificación de salud
- endpoints de lectura y actualización del perfil
- endpoints de carga y revisión de documentos

Usa las pruebas de API para verificar el contrato expuesto al frontend o a clientes externos.

Prefiere un test enfocado por ruta o paso del flujo, apoyado en muestras compartidas pequeñas, en lugar de un único test gigante de escenario.
