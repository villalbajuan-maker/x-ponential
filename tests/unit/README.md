# Pruebas unitarias

Coloca aquí las pruebas de funciones puras.

Ejemplos típicos:

- helpers de normalización
- constructores de nombres de archivo o rutas
- lógica de validación y fusión del perfil
- helpers de limpieza de texto OCR

Mantén estas pruebas rápidas y deterministas.

Prefiere un test enfocado por cada helper puro, incluso cuando varios helpers vivan en el mismo módulo.
